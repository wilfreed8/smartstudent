# 🎓 SmartStudent

Plateforme de révision intelligente pour étudiants marocains.
Projet full-stack basé sur **Laravel**, **React**, et **IA** (génération de quiz, résumé automatique, chatbot académique).

## 🧱 Structure
- **backend/** : API Laravel (authentification, cours, chapitres)
- **frontend/** : application React (interface utilisateur)
- **ai-service/** : microservice IA (Python)

## 🚀 Objectif
Créer une plateforme qui aide les étudiants à réviser plus efficacement grâce à l’intelligence artificielle.

## 🧑‍💻 Technologies
- Laravel 11
- React 18 + Tailwind CSS
- Python + Flask / API IA (Hugging Face / OpenAI)
- MySQL
- GitHub Actions (CI/CD)
